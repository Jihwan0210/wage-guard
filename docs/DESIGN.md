# Design System: 체불임금 계산 도우미 (wageback v2)

> stitch-design-taste 스킬 형식으로 정리한 디자인 규칙 문서. 새 화면을 만들거나 생성 도구에 시안을 맡길 때 이 문서를 기준으로 쓴다.
> 값의 원본은 `wt-v2/src/main/resources/static/css/app.css` 맨 위 `:root`. 이 문서와 값이 다르면 css 가 맞다. 토큰 표는 `_문서/디자인_시스템.md`(1~3단계 기준, 움직임 · 배치 절은 이 문서가 새것).

## 0. 로고 · 이름 (총괄 결정 2026-11-15, 바꾸지 않음)
- 노란 돌고래 그림 = **팀 노란돌고래의 마스코트이자 서비스 로고**. 그림은 `favicon.svg` · `app.js` 의 `dolphin()` 하나로 쓴다.
- 서비스 이름: **체불임금 계산 도우미** (영어 `Unpaid Wage Helper`, 베트남어 `Công cụ tính lương bị nợ`). '가칭' 표시는 뺐다.
- 앱바: 돌고래 + 서비스 이름. 팀 이름은 앱바에 넣지 않는다.
- 시작 화면 맨 아래와 `manifest.webmanifest` 설명 끝에 '만든 팀: 노란돌고래' 한 줄.

## 1. Visual Theme & Atmosphere
- 한 줄: 받지 못한 월급을 처음 계산해 보는 근로자(외국인 포함)를 위한, 믿음이 먼저인 공공 서비스형 앱. 설치한 휴대폰 앱처럼 조용하고 단단하게, 화려함은 결과 금액 한 곳에 모은다.
- 다이얼 (design-taste-frontend 기준): Variance 4 (왼쪽 정렬 · 넓은 화면 두 열 정도의 변화), Motion 3 (전환 · 눌림 · 시트만), Density 4 (매일 쓰는 앱 간격).
- 공공 · 접근성 우선 서비스라서 실험적 배치, 큰 장식, 끝없이 도는 애니메이션은 쓰지 않는다.

## 2. Color Palette & Roles
- **Paper White** (#FFFFFF) — 바탕. 어두운 화면은 **Night Navy** (#0E1420)
- **Mist Surface** (#F3F5F9) — 묶음 바탕(질문 목록, 안내 상자, 눌린 줄)
- **Deep Navy Ink** (#111B2E) — 본문 글씨 · 주 버튼 바탕 · 합계 카드 판
- **Slate Muted** (#4B5568) — 보조 글씨 (흰 바탕 7.5:1)
- **Hairline** (#E1E6EE) — 1px 구분선. 목록은 아래쪽 선 하나만
- **Dolphin Yellow** (#FFC21A) — 유일한 강조색. '지금 여기 · 결과' 에만: 진행 막대, 현재 탭 배경(옅은 #FFF5D1), 합계의 '원', 주 버튼 화살표 원. 글씨 색으로 쓰지 않는다(작은 노랑 글씨는 #7A5600)
- **Chart Blue** (#2F5BB5 / 어두운 화면 #5F8BEA) — 달별 막대 하나만. dataviz 검사기 통과(밝기 · 채도 · 바탕 대비 3:1)
- 상태색: 오류 #B42318, 확인 필요 #FFF5D1 + #5C4200, 끝남 #1E6B3C. 늘 아이콘이나 글과 함께
- 금지: 보라 · 하늘 그라디언트, 네온 빛, 순수 검정(#000000), 두 번째 강조색

## 3. Typography Rules
- **글꼴:** Noran Sans (Pretendard 를 한글 2,350자 · 라틴 · 베트남어로 줄인 파일, OFL). 영어 · 베트남어 · 한국어를 한 글꼴로 맞춘다. 외부 CDN 없음
- **제목:** 왼쪽 정렬, 두껍게(800), 자간 -0.025em, 줄은 2줄까지(시작 화면 320px 에서만 3줄 허용). 크기보다 굵기와 색으로 위계를 만든다
- **본문:** 16px 아래로 내리지 않는다. 보조 글씨 14px. 줄 간격 1.6. 큰글씨 모드는 19px 기준으로 모두 같이 커짐
- **숫자:** `tabular-nums`. 금액 옆에는 늘 읽기 쉬운 표기('796만 5,061원', 'about 7.97 million won')
- **문장:** 쉬운 존댓말, 화면마다 제목 한 줄 + 꼭 필요한 한두 줄. 법률 용어는 밑줄 단추로 풀이 시트
- 금지: 대시(—, –) 문자, '~할 수 있어요'만 이어지는 문장, 'AI 해설' 같은 기계 말투, 숫자 단계 머리글('01 02 03')

## 4. Component Stylings
- **주 버튼:** 남색 판 + 흰 글씨, 높이 56px(아래 고정 영역은 52px), 모서리 12px. 오른쪽 화살표는 노랑 옅은 원 안에(버튼 속 버튼). 누르면 98% 로 작아짐. 버튼 글은 일어날 일 그대로("진정서 초안 만들기")
- **보조 버튼:** 흰 바탕 + 1.5px 회색 테두리. 위험한 일은 빨간 판(`.btn-danger`)으로 시트 안에서만
- **목록 줄 (`.nav-row`):** 왼쪽 아이콘(#7A5600) · 글(+작은 설명) · 오른쪽 꺾쇠, 바깥 링크는 화살표. 높이 56px, 줄 전체가 단추. 밑줄 웹 링크 대신 쓴다
- **결과 항목 줄 (`.item-row`):** 이름 · 읽기 쉬운 금액(작게) · 금액 · 꺾쇠. 누르면 아래 시트에 쉬운 설명 · 계산식 · 법 근거
- **합계 카드 (`.receipt`):** 바깥 옅은 테(6px) 안에 남색 판(20px 모서리) 두 겹. 화면 전체에서 유일한 진한 판. 숫자는 0 에서 올라가며 나타남(움직임 줄이기면 바로)
- **시트 (`dialog`):** 휴대폰은 아래에서 올라오고 위 모서리 20px, 손잡이(40×5px), 바깥 누르기 · 끌어 내리기 · Esc 로 닫힘, 아래 버튼 1~2개. 넓은 화면은 가운데 창
- **탭 막대 (`.tabbar`):** 결과 뒤에만 4개(결과 · 절차 · 노동청 · 준비물), 아이콘 + 한 단어, 현재 탭은 아이콘 뒤 옅은 노랑 알약. 넓은 화면은 앱바 가운데 알약 탭
- **입력칸:** 라벨은 위, 오류는 아래 빨간 글씨, 포커스는 노랑 3px 테두리 그림자. 자리표시 글을 라벨 대신 쓰지 않음
- **읽는 중:** 실제 배치 모양의 뼈대(`.skel`, 은은한 빛 지나감). 빙글 도는 표시는 쓰지 않음
- **카드:** 높낮이가 뜻이 있을 때만(합계, 진정서 종이). 나머지는 바탕색 묶음이나 구분선

## 5. Layout Principles
- **휴대폰(960px 미만):** 위 앱바(뒤로 · 제목 · 큰글씨 · 언어) + 본문 스크롤 + 아래 고정 영역(주 버튼, 결과 뒤에는 탭 막대). 고정 영역 높이만큼 본문 아래를 비움. 안전 영역 `env(safe-area-inset-*)` 반영
- **넓은 화면(960px 이상):** 두 열. 왼쪽 본문, 오른쪽 따라 내려오는 칸에 버튼 · 안내. 결과는 왼쪽 합계 · 오른쪽 항목
- 한 화면에 질문 하나, 한 화면에 한 가지 일. 결과 화면은 합계 → 항목 → (접힌) 그래프 · 계산 기준 → 더 할 일 목록
- 개인정보 · 법률 안내는 필요한 곳에 한 번씩(시작 화면, 진정서 입력, 결과 합계 아래 한 줄)
- 320px 에서 가로 스크롤 없음. 누르는 곳 44px 이상(탭 56px)

## 6. Motion & Interaction
- 화면 이동: 앞으로는 오른쪽에서 32px 밀려 들어옴, 뒤로는 왼쪽에서(280ms), 탭끼리는 살짝 나타나기(200ms). 브라우저 · 안드로이드 뒤로 버튼과 같이 움직임
- 시트: 아래에서 올라옴(300ms), 끌면 손가락을 따라 내려옴
- 눌림: 98% 작아짐 + 배경색. 곡선은 `cubic-bezier(0.2, 0.8, 0.2, 1)` 하나
- `transform` · `opacity` 만 움직인다. `prefers-reduced-motion: reduce` 면 모두 끔
- 저사양 폰: GSAP 같은 움직임 라이브러리, 스크롤 따라 움직이기, 끝없이 도는 장식 금지. 흐림(backdrop-filter)은 고정된 앱바 · 아래 고정 영역에만

## 7. Anti-Patterns (Banned)
- 이모지, 보라 · 하늘 그라디언트, 네온 빛, 순수 검정
- '01 02 03' 숫자 단계 소개, 작은 머리글(eyebrow) + 큰 제목 + 설명 + 아이콘 3개 줄 세우기
- 같은 카드 반복, 두꺼운 그림자, 테두리 상자 안의 상자, 점 무늬 배경, 장식 원
- 화면마다 붙는 개인정보 · 법률 문단, 같은 뜻의 버튼 두 개
- 'AI 해설' 같은 표현(자동 생성 고지는 상세 시트에 작게 한 번), 과장 · 광고 말투, 느낌표
- 배경 트랙이 있는 비율 막대(항목 옆 막대는 뺐다), 두 축 그래프
- 스크롤 끝 안내('아래로 내려 보세요'), 버전 표시, 지어낸 숫자

## 스킬에서 고르지 않은 것 (우리 서비스와 안 맞음)
- gpt-taste 의 GSAP 고정 · 스크럽 · 카드 쌓기, 큰 사진 배경: 저사양 폰 · 접근성 원칙과 충돌
- design-taste-frontend 의 '아이콘을 직접 그리지 말 것' · 아이콘 라이브러리: 라이브러리를 더하면 무거워져서, 1단계에서 만든 선 굵기 1.75 직접 그린 아이콘 한 벌을 유지
- minimalist-ui 의 세리프 제목 · 따뜻한 회색: 3개 언어를 한 글꼴로 맞추는 것이 우선
- high-end-visual-design 의 모든 카드 두 겹 테 · 큰 여백(py-24 이상): 합계 카드 하나에만 두 겹 테를 썼다
